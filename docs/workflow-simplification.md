# Workflow simplification and six-module contract

Date: 2026-09-08. User explicitly authorized removing unnecessary engineering code.
Recovery point before this work: d558b5f. The private configuration project, Vault,
runtime evidence, uncommitted/untracked assets and ignored build artifacts were
not deleted. This list contains only previously tracked engine/test files.

## Kept core

- Existing RSS/full-body collection, source catalog and approved user context.
- Bounded section-aware evidence packets; original author preserved as metadata.
- Luna prepare → Generator → independent Reviewer → finalize.
- Six required sections; each gets up to two candidate choices and one final item.
- URL/evidence mapping, valid user references, complete independent review.
- Existing OS lock, no-overwrite writer, durable publish receipts and recovery.

The source-health denominator is unchanged. The old second gate counted unrelated
RSS bodies; body availability now reports how many of the six required modules
have real free evidence. Missing module bodies or a failed module review cannot
produce a partial six-module brief.

## Editorial changes

Plain title/body/takeaway/connection replaces the legacy rigid claim-role input.
Python still derives IDs and review requirements for every substantive block.
A single bounded revision opportunity covers either structural repair or a
targeted editorial correction; edited drafts require a fresh independent review.
Normal role executions: 2. With editorial correction: at most 4. No unlimited
rewrite or provider fallback. Unresolved failures remain explicit.

Recent material is preferred. An empty module can use a previously unselected
free essay within one year, marked with its original date as extended reading.
GitHub recommendation checks public README, license, archived status and user fit;
a bounded public repository search can replenish the initial Agent/eval pool.
No project is installed or executed.

## Retired implementation

The native TCB, Rust qualification, AppContainer/WFP, Codex process runner/proxy,
DeepSeek transport/strategy, duplicate source proof/activation contracts and their
obsolete qualification tests were removed. Their tests were retired with those
features, not changed to accept unsafe behavior. Useful evidence packet behaviors
were extracted first and passed unchanged old regression tests before replacement.
